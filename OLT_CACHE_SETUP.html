How to Enable:

  1. Go to Notification Settings > Pengaturan Lanjutan Tab
  2. Scroll down to Cron Jobs table
  3. Find: "Auto Cache Data OLT (Multi Brand)"
  4. Click "Turn On" button in Aksi column
  5. ✅ System will now cache OLT data every 5 minutes automatically

How It Works:

Page Load (olt.php)
    ↓
[1] Check localStorage for cached data
    ↓
    If valid (< 5 min old) → INSTANT DISPLAY ✓ (< 1 second)
    ↓
[2] Background: Fetch fresh data from getdata/olt-cache.php
    ↓
[3] Update cache + table (every 5 minutes via cron)

What Gets Cached:

  • ✓ All OLT data (IP, Name, Brand, Type)
  • ✓ Credentials (username, password)
  • ✓ Server/Area information
  • ✓ SNMP community strings (for CDATA)
  • ✓ Console access methods

Performance Improvement:

BEFORE (without cache):  Page load 5-10 seconds (always fetch from OLT)
AFTER (with cache):      Page load < 1 second   (from localStorage)
                         Background: Update every 5 minutes

Cron Job Details:

  • Name: Auto Cache Data OLT (Multi Brand)
  • Frequency: Every 5 minutes (*/5 * * * *)
  • Command: curl {domain}/crm/billing/getdata/olt-cache.php
  • Purpose: Keep cache fresh without user waiting
  • Toggleable: Yes - turn on/off from Cron Jobs table

Direct Access (Advanced):

Check cache status:  GET /crm/billing/getdata/olt-cache.php
Manage cron:         POST /crm/billing/getdata/olt-cron-manager.php
  Parameters:
    action=get_status  → Get current cron config
    action=enable      → Enable cron job
    action=disable     → Disable cron job
    action=run_now     → Trigger immediate update
    action=set_interval&interval=5  → Set interval (1-60 min)

Browser Cache Location:

  • Key 1: qts_olt_data_cache (stores OLT data array)
  • Key 2: qts_olt_cache_time (stores timestamp)
  • Validity: 5 minutes from last update
  • View: DevTools → Application → Local Storage
